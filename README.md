# Codaria SaaS

Plataforma SaaS multi-tenant para gestão de barbearias e salões de beleza. Em desenvolvimento.

Multi-tenant SaaS for barbershop and salon management. Work in progress.

## Sobre / About

**PT:** A ideia é centralizar agendamento, clientes, profissionais, serviços, estoque, financeiro, comissões e relatórios em um único produto, com dados isolados por estabelecimento.

**EN:** The goal is to centralize scheduling, clients, staff, services, inventory, finance, commissions, and reports in a single product, with data isolated per establishment.

## Stack

- Next.js
- React
- TypeScript
- PostgreSQL
- Drizzle ORM
- Tailwind CSS
